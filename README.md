# 🚀 Projetos em destaque

## 🏥 e-Clin — Sistema de Gestão para Clínicas-Escola

Sistema desenvolvido durante a Prática Orientada em Computação da
Universidade Federal de Sergipe.

A aplicação foi criada para atender necessidades reais das clínicas-escola
da universidade, incluindo agendamento e prontuário eletrônico.

**Stack:**

`FastAPI` `SQLAlchemy` `Alembic` `Pydantic` `PyJWT` `Pytest`

`Next.js` `React` `TypeScript` `Tailwind CSS`

`Docker` `Docker Compose` `GitHub Actions`

O projeto envolveu aproximadamente **360 horas de desenvolvimento**,
passando por definição de requisitos, arquitetura, implementação,
testes, documentação da API e deploy.
